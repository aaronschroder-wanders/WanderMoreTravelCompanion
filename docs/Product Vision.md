# Wander More Travel Companion

## Vision

A simple, offline-first travel companion that helps travellers organise trips, track spending, and keep important travel information together.

## Target Users

Initially:
- Aaron and Sarah during their own travels

Eventually:
- Couples
- Families
- Independent travellers
- Long-term travellers

## Problem We Are Solving

Travellers currently use a mixture of:
- spreadsheets
- notes apps
- booking emails
- paper documents
- banking apps

This makes it difficult to understand:
- what has been booked
- what has been spent
- where money is going

## Product Goal

Create a single travel companion where users can:

- plan trips
- store bookings
- record expenses
- understand total trip costs

## Key Principles

- Offline first
- Simple to use while travelling
- Accurate expense tracking
- Designed for longer trips
- Built so sharing between travellers can be added later
