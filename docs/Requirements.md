# Requirements

## Version 1 Goal

Create a personal offline travel tracker that allows users to create trips and record expenses.

## Functional Requirements

### Trips

Users can:
- create a trip
- define start and end dates
- choose a home currency

### Expenses

Users can:
- add expenses
- select a category
- enter foreign currency amount
- enter exchange rate used
- calculate home currency value
- view totals by category

### Categories

Initial categories:

- Accommodation
- Transport
- Food
- Activities
- Shopping
- Insurance
- Flights
- Other

## Future Features

- Shared trips
- Multiple users
- Cloud synchronisation
- Bookings
- Places to visit
- Itinerary calendar
- Reports
